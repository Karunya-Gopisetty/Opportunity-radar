
# 🚀 Opportunity Radar

Opportunity Radar is a beginner-friendly Python project that helps users manage opportunities such as hackathons, internships, and workshops.

## ✨ Features

- Add new opportunities
- View all saved opportunities during the current session
- Delete opportunities
- Count total opportunities
- Search for an opportunity by name
- Simple menu-driven interface

## 🛠️ Technologies Used

- Python
- Lists and dictionaries
- While loops
- Conditional statements
- User input and output
- List methods and enumeration

## ▶️ How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Open a terminal in the project folder.
4. Run:

   `python "opportunity radar 1.py"`

5. Follow the menu displayed in the terminal.
